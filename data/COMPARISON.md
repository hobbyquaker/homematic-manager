## What the new data does not carry

- The per-profile `options` block of the 2.x files (which parameter the dialog offers as a
  dropdown for _this_ profile). openccu-data flattened it to one list per sender type, which is
  kept as `ReceiverProfiles.senderMetadata`; the per-profile granularity is gone.
- The `input` hints of those options (`EnterTime_h_m_s`, `EnterPercent`). The paramset
  description (`TYPE`, `UNIT`, `MIN`, `MAX`) carries the same information, so task 8 can derive
  the editor from the description instead of from a hard-coded hint.
- `UI_DEFINITION_1_1` / `_1_2`, the radio-button labels of four profiles ("gekippt oder ganz
  offen"). openccu-data drops them too.
