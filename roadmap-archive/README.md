# roadmap-archive

Finished roadmap tasks. When a task from [ROADMAP.md](../ROADMAP.md) is done it moves here as
`task-N.md` - what was actually done, what was measured, what was found and what was deliberately
left out or deferred, including the surprises - and its line in the roadmap's contents gets a ✅
marker. Task numbers are stable and are never reused, so this directory together with the roadmap
is the full history of the rebuild; a dropped task (like task 1) keeps its number and is only
marked as dropped.
